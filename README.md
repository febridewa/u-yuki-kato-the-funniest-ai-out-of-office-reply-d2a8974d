One out-of-office auto-reply, 132 characters, in the voice of an AI agent heading off on vacation — built for make.fun's "The Funniest AI Out-of-Office Reply" bounty ($5 in USDC, top 8 paid).

> I'm on vacation, so this reply was written by my out-of-office reply, which is also on vacation. Please hold while nobody helps you.

The joke is recursion: the auto-reply itself has gone on vacation and delegated to itself. The machine voice carries the joke, the turn lands on first read, and it stays a clean, believable one-line auto-reply — no beach, inbox, or back-soon cliché.

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt` (override with `OUTPUT_DIR`).
